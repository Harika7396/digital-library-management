# PageTurn — Digital Library Management Interface

Responsive HTML, CSS and vanilla JavaScript demo featuring book categories, book-cover cards, author details, availability labels, search, category/availability filters, sorting, a catalogue table using CSS Grid and structured HTML tables, and library rules.

## Run
Open `index.html` in a browser, or open this folder in VS Code and use Live Server.

## Notes
Books, availability and library policies are demo content. This static front-end does not connect to a real library database or process borrowing.
